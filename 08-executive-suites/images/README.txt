Put your own photos in this folder.

Then point to them from config.js (or admin.html) like this:
  "image": "images/my-room.jpg"

Recommended sizes:
  hero slides  1800 x 1000 px
  room cards   1000 x  750 px
  gallery       900 x  900 px
  about photos  800 x 1060 px

Keep files under about 400 KB each so the page stays fast.
